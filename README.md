# Market Backtesting Demo

Browser-ready Streamlit project for NIFTY 50, BANKNIFTY and TMPV strategy testing.

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload all files from this folder.
3. Open Streamlit Community Cloud and choose the GitHub repository.
4. Select `app.py` as the main file.
5. Deploy.

The app includes sample demo data so it can be tested immediately.

**Important:** sample price data is synthetic and is only for testing the application, not for investment decisions.

## Local run

```bash
pip install -r requirements.txt
streamlit run app.py
```
